# 📚 MLE Handbook

## Introduction

A universal handbook for Machine Learning Engineers (MLE), organized as a network of interconnected notes.

## How to View the Notes

This repository is structured using [Obsidian](https://obsidian.md), a knowledge management tool that uses **bi-directionally linked Markdown notes**. As a result, it may not render properly for direct reading on GitHub.

To view and explore the content as intended:

1. **Install Obsidian** (free) from [https://obsidian.md](https://obsidian.md).
2. **Clone or download** this repository to your local machine.
3. **Open the folder as a vault** in Obsidian:
   - Launch Obsidian
   - Click "Open folder as vault"
   - Select the downloaded folder
